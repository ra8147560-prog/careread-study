Random assignment schedule

Balanced block randomization: every block of six participants contains each condition once, in random order. The same seed always gives the same schedule, so print it once and follow it in order. Each link already fills in the participant ID.

ParticipantBlockConditionLink

Running a session

  1. Open the scheduled link in Chrome on the 1920 × 1080 lab monitor at 100% zoom. Press Start; the page switches to full screen.
  2. Calibrate the eye tracker, then hand over. Flow: scenario → fixation cross → report → fixation cross → advisor introduction → chat 1 → chat 2 → chat 3 and decision → questionnaire.
  3. Each screen sets an address marker for segmenting recordings: #scenario, #report, #advisor, #t1-typing, #t1, #t2, #t3, #t3-decision, #done.
  4. Data (decision, times, screen log, AOI positions) go to Google Sheets; the participant is then taken to the questionnaire.
